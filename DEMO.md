# Ручная проверка лендинга и кабинета (стабы)

Без бэкенда: данные и бронь идут через in-process stubs.

## Запуск

```bash
yarn dev
```

Откройте http://localhost:5173/

## Chrome

- Переключение **День / Ночь** в шапке.
- Язык **RU / EN** (на ширине ниже 768 — кнопка языка; с 768 — сегмент RU|EN и подпись темы).
- В футере нет строки про «нарисованы кодом».
- Подвал: телефон + email слева, © справа (`space-between`); на узких экранах колонка. Навигационных ссылок в подвале нет (они в шапке).
- В шапке пункт **О нас** → `/about`.

## Доверие: главная + «О нас»

1. На главной: Hero → каталог `#catalog` → мост «О прокате» с CTA → `/about`.
2. Полный контент на `/about` (сверху вниз): О прокате + Место/карта (`#place`), How (`#how`), Trust (`#trust`), Контакты (`#contacts`).
3. SPA-навигация (шапка, CTA, хеши вроде `/#catalog`) скроллит через `ScrollRestoration` data router.

## Успех: бронь гостем

1. На главной — Hero, каталог из 20 драконов (PNG-анимация), ниже мост «О прокате».
2. Откройте любого дракона (например Кристаллион `/dragons/2`) или Сакурку **вне** окна 10:00–12:00.
3. Период: по умолчанию завтра 13:00–15:00 → «свободно» → **Продолжить**.
4. Контакты: имя + валидный email → **Получить код**.
5. OTP: код `480010` → **Подтвердить бронь**.
6. Layout дракона остаётся: слева карточка, справа панель со степпером (**Готово**) — **«Бронь создана»**, номер `DR-……`, CTA **Открыть бронь** (в кабинет на эту бронь). После OTP сессия кабинета уже открыта.

## Бронь по сессии (без OTP)

1. Войдите в кабинет (см. ниже) **или** только что завершите гостевую бронь.
2. Откройте другого дракона, например `/dragons/3`.
3. Степпер короткий: **Период | Готово**. Кнопка на периоде — **Забронировать** (не «Продолжить»).
4. Ожидание: сразу **«Бронь создана»** и **Открыть бронь**, без шагов контактов и кода.

## Кабинет: вход

Demo-почта с бронями: **`anna@example.com`**, OTP **`480010`**.

1. Шапка → **Мои брони** → `/cabinet/login`.
2. Email `anna@example.com` → **Получить код** → `480010` → **Войти**.
3. Список броней: текущие / прошедшие, головы драконов 32×32, скелетоны при загрузке **без** текста «Загружаем брони» в теле списка.
4. Карточка брони: спрайт, статусы, **Отменить бронь** (если можно).
5. **Профиль**: имя/телефон → **Сохранить**; **Выйти**.

### Отказ: нет броней на почте

1. На `/cabinet/login` введите email без броней, например `nobody@example.com`.
2. **Получить код**.
3. Ожидание: код **не** уходит; сообщение «Броней на эту почту нет» и ссылка **В каталог**.

Все страницы кабинета с `noindex`.

## Отказ: слот занят (на шаге периода)

1. `/dragons/1` (Сакурка).
2. Поставьте начало/конец так, чтобы интервал пересекал **10:00–12:00** в тот же день.
3. Ожидание: статус «занято», кнопка **Продолжить** / **Забронировать** неактивна — до create/OTP не доходите.

## Отказ: неверный OTP

1. Дойдите до шага кода по сценарию гостя (слот свободный).
2. Введите любой код кроме `480010` и `409409` → **Подтвердить бронь**.
3. Ожидание: ошибка кода, счётчик попыток; после исчерпания — состояние «код исчерпан» / resend.

## Отказ: конфликт 409 (шаг «Ошибка»)

Имитация гонки: период был свободен, но к моменту create слот уже заняли.

1. Тот же путь, что у гостя, до шага кода (свободный слот).
2. OTP: код `409409` → **Подтвердить бронь**.
3. 4-й шаг степпера — **Ошибка** (вместо «Готово»), Note в панели:
   - «Это время уже заняли»;
   - **Изменить время** → снова шаг периода;
   - **Другой дракон** → каталог `/`.

## 404 и футер

- `/dragons/124` и `/nope` — «Такой страницы нет», по центру; футер у низа экрана (десктоп).
- На коротких страницах футер прибит вниз (`100dvh` + flex).

## Загрузка

При медленном CPU на `/dragons/:id` и карточке брони кратко виден EmptyState-loader (жемчужина) **без** рамки-плитки, по центру.
